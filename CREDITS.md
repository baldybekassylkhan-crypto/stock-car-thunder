# Credits

All art in Stock Car Thunder is generated procedurally in code at load time: the track, car models,
liveries, asphalt/grass/sand/concrete textures, crowd, catch fence, sky and terrain. No image, model
or audio files are downloaded.

Engine, tire and wind sounds are synthesised with the Web Audio API.

## Libraries
- [three.js](https://threejs.org/): MIT
- [Rapier](https://rapier.rs/) (`@dimforge/rapier3d-compat`): Apache-2.0
- [PeerJS](https://peerjs.com/) (multiplayer, from milestone 3): MIT
- Fonts: [Barlow / Barlow Condensed](https://fonts.google.com/specimen/Barlow) via Google Fonts: OFL

All team names, sponsors, numbers and track names are fictional. This game is not affiliated with
or endorsed by NASCAR or any racing series.
